# threejs_train

Procedural anime-style station platform (Three.js, no build step).

- Live: https://ryoheimongami8.github.io/threejs_train/
- Local: `python serve.py 8048` then open http://localhost:8048/ (export writes PNG layers into `out/`)
- On GitHub Pages, "Export layers" falls back to browser downloads.
- Drag = look, Shift+drag = pan, wheel = move. Panel on the right: style, light, camera, rules, seeds, export.
- Reference photos are not included; the overlay feature needs your own images in `photo/`.
